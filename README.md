# 🎓 Aschool - Educational Platform

## 📚 About the Project

Aschool is an educational web platform designed to provide a simple and organized learning environment for users, teachers, and administrators.

The platform allows users to browse and enroll in courses, follow lessons, track their learning progress, and save favorite courses.

Teachers can create and manage courses and lessons, while administrators can manage users, categories, and review submitted courses.

## ✨ Features

- User registration and login
- User profiles
- Profile picture upload
- Role-based access control
- Course browsing and enrollment
- Lesson management
- Lesson progress tracking
- Favorite courses
- Teacher dashboard
- Admin dashboard
- Course review and approval system
- Category management
- Course and category images
- Arabic user interface

## 👥 User Types

### User
- Browse courses
- Enroll in courses
- Watch lessons
- Track progress
- Add courses to favorites
- Manage profile

### Teacher
- Create courses
- Upload course images
- Add and manage lessons
- Edit and delete courses
- Submit courses for admin review

### Admin
- Manage users
- Approve or reject accounts
- Manage categories
- Manage category images
- Review submitted courses
- Approve or reject courses

## 🎯 Project Purpose

This project was developed for educational purposes to practice web development, database management, authentication, authorization, and content management.
